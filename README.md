# Карточки на A4

Локальная desktop-программа на Python / PySide6 для подготовки аккуратных копий двух сторон документа к печати. PDF, JPG, JPEG и PNG → выделение четырёх углов → белый A4 → PDF или PNG 300 DPI. Интерфейс на русском языке.

## Установка и запуск

Нужны Python **3.12+**, [uv](https://docs.astral.sh/uv/) и графическая среда Windows, Linux или macOS.

```bash
uv sync
uv run cardprint
```

`uv run cardprint` также устанавливает отсутствующие зависимости при первом запуске. После установки зависимостей приложение работает без сети; для явно автономного запуска: `uv run --offline cardprint`.

Зависимости фиксируются в `uv.lock`. В приложении нет API, серверов, аккаунтов, OCR, LLM, телеметрии и генеративной обработки. Исходные документы открываются только для чтения, в логи не записываются. Установка пакетов через uv требует сети или заполненного локального кэша.

На Linux при наличии Wayland приложение использует его автоматически. Явный `QT_QPA_PLATFORM` имеет приоритет. Для X11 нужны системные библиотеки Qt; в Ubuntu / Debian их можно установить так:

```bash
sudo apt install libegl1 libgl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0
```

## Как подготовить документ

1. Нажмите **«Добавить файлы»** (`Ctrl+O`), выберите две фотографии или PDF. Слева появятся миниатюры, для PDF — каждая страница. Полная PDF-страница загружается только при назначении стороны.
2. Выберите миниатюру и нажмите **«Назначить лицевой»** или **«Назначить обратной»**. Двойной щелчок назначает следующую сторону. Карточки «Лицевая сторона» и «Обратная сторона» над редактором выбирают редактируемую сторону.
3. Проверьте автоматически найденный контур: область вне выделения затемнена, углы пронумерованы **1–4**. При перетаскивании угла появляется **лупа 4×** из исходных пикселей; неверный контур сразу подсвечивается красным с пояснением в строке состояния. Выбранный щелчком угол можно сдвигать стрелками на **1 пиксель**, а `Shift + стрелка` — на **10 пикселей**. Перетащите углы либо нажмите **«Выделить 4 точки»** и щёлкните верхний левый, верхний правый, нижний правый и нижний левый углы. Во время незавершённого ввода 4 точек или перетаскивания угла экспорт приостанавливается; `Esc` отменяет правку и возвращает прежние углы. Выпуклое выделение обязательно; пересекающиеся стороны блокируют экспорт с пояснением.
4. Колесо мыши и кнопки `− / +` меняют масштаб, перетаскивание фона перемещает изображение. **«Вписать»** (`0` на холсте) показывает изображение целиком. Координаты углов сохраняются при масштабировании и изменении окна. **«Повернуть на 90°»** (`R` в редакторе) поворачивает изображение и выделение вместе. Клавиши редактора не мешают вводу в поля параметров.
5. Настройте размер каждой стороны. По умолчанию — **85,60 × 53,98 мм**. Можно сохранить пропорции выделения, задав ширину, или указать ширину и высоту самостоятельно. При изменении пропорций более чем на 0,5% появляется предупреждение. Для проверки краёв откройте **«Увеличить результат / края»**; доступен просмотр пиксель к пикселю (открытое окно просмотра помечается как устаревшее при последующих правках стороны).
6. При необходимости задайте радиус углов в миллиметрах. Нулевой радиус сохраняет прямоугольное выделение целиком. Скругление делает белыми только участки за пределами выбранного закруглённого контура.
7. На вкладке **«Предпросмотр A4»** проверьте весь лист. По умолчанию стороны расположены по центру друг под другом с промежутком **15 мм** и минимальными полями **10 мм**. Доступен шаблон **«Рядом»**, общий сдвиг по X/Y, поля и промежуток. Параметры не подгоняются молча: при выходе за поля A4 экспорт недоступен до исправления. Группу можно сдвинуть перетаскиванием любой карточки: смещения X/Y обновляются в миллиметрах, движение ограничено полями, в пределах **0,8 мм** от центра включается привязка с направляющей. Один жест — один шаг отмены; `Esc` отменяет перемещение. Переключатели **«Линейки · мм»** и **«Поля»** управляют только экранными направляющими. Опция **«Метки реза»** добавляет в предпросмотр, PDF и PNG линии длиной **3 мм**, на расстоянии **1 мм** от углов, толщиной **0,15 мм**. Если метка пересекает другую карточку или край листа, она пропускается с пояснением в статусе; размер карточек сохраняется. Кнопки **«Добавить текст»** (вставка по клику на лист) и **«Водяной знак»** (штамп с фиксацией даты на момент вставки) позволяют добавлять надписи поверх листа A4; их текст, шрифт, выравнивание, размер, поворот, прозрачность и цвет настраиваются в правой панели, положение корректируется перетаскиванием, двойной клик открывает редактирование текста, а `Delete` удаляет выбранную надпись (все правки входят в историю `Ctrl+Z` / `Ctrl+Shift+Z`, а выход за границы листа подсвечивается пунктиром и блокирует экспорт).
8. Нажмите **«Сохранить PDF»** (`Ctrl+S`) либо **«PNG · 300 DPI»**. Существующий файл заменяется только после подтверждения. Перезапись любого импортированного оригинала запрещена, включая убранные из списка файлы. После сохранения доступна кнопка открытия файла; если после экспорта внесены новые правки, кнопка показывает **«Открыть ранний экспорт»** (экспорт PDF/PNG не сохраняет редактируемый проект). При закрытии окна с неэкспортированными правками программа запросит подтверждение.

**Для сохранения размера печатайте в масштабе 100% / Фактический размер.** Отключите подгонку под страницу в программе печати. Приложение экспортирует файл, печать выполняется в системной программе.

**«Сбросить выделение»** возвращает четыре угла к границам текущего изображения. **«Сбросить правки стороны»** дополнительно отменяет поворот, скругление и изменение размера. Доступны кнопки **«Отменить»** (`Ctrl+Z`) и **«Повторить»** (`Ctrl+Y` / `Ctrl+Shift+Z`) для шагов редактирования и компоновки (до 50 шагов и до 256 МиБ удерживаемых оригиналов в истории). Повторное редактирование всегда использует загруженный оригинал, поэтому интерполяционные потери не накапливаются. **«Убрать сторону»** очищает её назначение; **«Убрать выбранный файл»** удаляет только миниатюру, а не исходный файл или уже назначенную сторону. Если исходный файл изменился на диске после добавления, обработка и экспорт блокируются до нажатия **«Перезагрузить выбранный файл»**.

## Качество и ограничения первой версии

- Окружение за четырёхугольным контуром отбрасывается. Фон листа строго RGB **255, 255, 255**. Включённые вручную метки реза печатаются чёрными линиями поверх белого листа. Тени **внутри** выделения сохраняются вместе с изображением; автоматического удаления теней внутри документа нет.
- Содержимое карточки не восстанавливается и не перерисовывается. Нет пороговой обработки, повышения резкости, подавления шума или цветокоррекции. Фотографии приводятся к RGB, учитывается EXIF-ориентация, прозрачность компонуется на белом фоне. Специализированное ICC / CMYK управление цветом не реализовано.
- Коррекция перспективы выполняется с билинейной интерполяцией. Выходная сетка определяется максимальными длинами противоположных сторон выделения. Пропорции, рассчитанные по фотографии с перспективой, являются оценкой; для удостоверений используйте известный физический размер.
- В PDF изображения записываются без JPEG-пересжатия и без уменьшения разрешения обработанного результата. PDF-источник растеризуется в **300 DPI**, векторные объекты и текст не переносятся как векторы. Повышение DPI не восстанавливает детали низкокачественного скана.
- PNG имеет размер **2480 × 3508 пикселей** и метаданные 300 DPI. Предпросмотр использует те же координаты и размеры, но экранный растр меньше; сглаживание в стороннем PDF-просмотрщике может незначительно отличаться.
- Автоматический контур — предварительная подсказка. На сложном фоне может потребоваться ручное выделение.
- Защищённые паролем PDF не открываются: нужна локальная копия без пароля. Повреждённые файлы сопровождаются сообщением. Лимит на изображение / отрендеренную страницу / результат — **80 мегапикселей**. Чтение и рендеринг PDF выполняются в отдельном фоновом процессе, миниатюры подгружаются пакетами, а кэши миниатюр (до 32 МиБ) и отрендеренных страниц (до 128 МиБ) ограничены по памяти.
- Можно экспортировать одну назначенную сторону; интерфейс явно показывает количество сторон на листе. Сохранение сессий не реализовано; доступны отмена/повтор правок (`Ctrl+Z` / `Ctrl+Y`) и сброс к оригиналу.
- Загрузка, определение контура, обработка, подготовка предпросмотра и экспорт идут в фоновых задачах с индикатором. Устаревшие результаты правок игнорируются. При закрытии приложение завершает текущие операции.
- Промежуточные документы на диск не записываются. Экспорт сначала создаёт временный файл рядом с целевым, затем публикует результат; временный файл удаляется и при обычной ошибке. Аварийное завершение процесса ОС может оставить `.cardprint-*.tmp` рядом с файлом экспорта.

## Проверки

```bash
uv sync --dev
uv run pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
```

Тесты GUI по умолчанию используют Qt `offscreen` и не требуют дисплея. Для проверки в настоящем графическом сеансе Linux:

```bash
QT_QPA_PLATFORM=wayland uv run pytest -q tests/test_ui.py
# либо QT_QPA_PLATFORM=xcb для X11 с установленными системными библиотеками
```

Проверяются преобразования координат и реальные перетаскивания углов Qt, неверные четырёхугольники, перспектива, поворот и сброс, EXIF, прозрачность, защищённые и повреждённые файлы, размеры A4 и обеих карточек внутри PDF, белый фон, исходное разрешение без JPEG, PNG 300 DPI, защита от перезаписи и неизменность оригиналов. Интеграционный сценарий проходит импорт → назначение двух сторон → правки → предпросмотр → экспорт через интерфейс.

Искусственные примеры без персональных данных:

```bash
uv run python scripts/make_demo.py
```

В `demo/` появятся `front.png`, `back.png` и `two_pages.pdf`. Скрипт не заменяет существующие примеры. Для проверки интерфейса с сохранением снимков окна и экспортов:

```bash
QT_QPA_PLATFORM=wayland uv run python scripts/gui_smoke.py
```

На Windows / macOS выполните последнюю команду без префикса `QT_QPA_PLATFORM=wayland`. Результаты сохраняются в новом подкаталоге `artifacts/`.

## Код

- `pdf_worker.py` — отдельный дочерний процесс для `PyMuPDF`, пакетная генерация миниатюр, ограниченные LRU-кэши и проверка сохранённого PDF.
- `imaging.py` — чтение источников, EXIF, контур, перспектива, скругление; неизменяемые исходные массивы.
- `geometry.py` — координаты изображения, преобразование редактора, проверка выделения и общая геометрия листа в миллиметрах.
- `model.py` — доменная модель карточки (`Card`) и названия сторон без зависимости от Qt.
- `export.py` — предпросмотр, PNG и PDF из общей модели `Sheet`, безопасное сохранение, защита оригиналов и проверка отпечатков исходных файлов; миллиметры переводятся в точки только при записи PDF.
- `ui/editor.py` — QGraphicsView: сцена в пикселях оригинала, независимые масштаб и перемещение представления.
- `ui/window.py`, `ui/tasks.py` — русский интерфейс, состояние сторон, фоновые задачи и защита от устаревших результатов.
- `tests/` — автоматические проверки на искусственных карточках.
